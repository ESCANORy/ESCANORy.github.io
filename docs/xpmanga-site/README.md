# XPManga Official Site

This branch contains the static-first Pre-release website snapshot for xpmanga.com.

- P0 routes: /, /download, /sources, /help and /en/* equivalents.
- Source surface: xpmanga-sources/ was preserved unchanged.
- Public projections: data/release.json, data/sources-projection.json, data/feature-publication-gate.json.
- No backend, analytics, legal pages, DNS changes, or public release activation are included.
