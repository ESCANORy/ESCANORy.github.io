# XPManga — Design Direction

## Three Directions Considered

### Theme Name: Midnight Reader Console
Very Brief Intro: واجهة منتج تقنية ليلية هادئة، تعكس قارئًا متعدد المصادر وتضع حالة الإصدار والثقة قبل الزخرفة. تستخدم بنية غير متماثلة ومساحات مركزة بدل قالب Landing Page عام.
Probability: 0.07

### Theme Name: Editorial Paper Trail
Very Brief Intro: اتجاه تحريري فاتح يقدّم XPManga كدليل موثوق وواضح، بطباعة عربية بارزة وتقسيمات شبيهة بالمجلات التقنية. يعطي الأولوية للقراءة والشفافية على الطابع المنتجّي الداكن.
Probability: 0.03

### Theme Name: Signal Garden
Very Brief Intro: واجهة تقنية فاتحة مع إشارات لونية صغيرة وحالات تشغيلية واضحة، تمنح صفحات المصادر والمساعدة طابعًا عمليًا ودودًا دون تحويلها إلى لوحة تحكم.
Probability: 0.05

## Chosen Direction: Midnight Reader Console

### Design Movement
واجهة منتج تقنية معاصرة مستلهمة من لوحات القراءة الليلية وMaterial 3، لكن بصياغة تحريرية رسمية لا تشبه لوحة تحكم أو تطبيقًا عامًا.

### Core Principles
1. الوضوح قبل الإبهار: حالة الإصدار وحالة التكامل والـCTA تتقدم على الزخرفة.
2. الثقة عبر الحدود: نفصل دائمًا بين XPManga والتكامل والموقع الخارجي.
3. المنتج لا المحتوى: لا أغلفة مانجا ولا عناوين أو صور من مصادر خارجية.
4. الهاتف أولًا: RTL/LTR، الوصول، وحالات الفشل جزء من التصميم الأساسي.

### Color Philosophy
يستخدم السطح الليلي `#07071A` ليعكس هوية التطبيق الحالية، بينما يوجه البنفسجي `#6D28D9` الفعل الأساسي دون عدوانية بصرية. البنفسجي الفاتح يميز المعلومات والحالات غير الحرجة، والمغنطيسي `#FF2D86` يبقى لمسة صغيرة مرتبطة بعلامة XP. ألوان الحالة لا تعمل وحدها؛ يرافقها نص وأيقونة.

### Layout Paradigm
تخطيط غير متماثل: Hero مقسوم بين رسالة واضحة وإشارة بصرية مجردة، ثم أقسام بطول قراءة متدرج، وبطاقات الحالات مرتبة حسب القرار الذي يحتاجه المستخدم. على الهاتف يتحول كل قسم إلى مسار رأسي قابل للمس، وعلى Desktop يحتفظ بترتيب القراءة العربي أو الإنجليزي دون إضافة محتوى غير موجود.

### Signature Elements
1. علامة XP الحالية في الرأس وبجوار حالات الإصدار، دون إعادة رسم الشعار أو تحويله إلى Wordmark مصطنع.
2. خطوط اتصال رفيعة بين أيقونات «نزّل، أضف، اقرأ» لتوضيح تدفق المنتج.
3. شارات حالات ذات سطح منخفض التشبع مع رمز ونص، لا لون منفرد.

### Interaction Philosophy
التفاعل يطمئن المستخدم ولا يستعرض التقنية: الضغط يرد بسرعة، الـAccordion يكشف التفاصيل عند الطلب، الرابط الخارجي يصرّح بالخروج من الموقع، والـCTA لا يظهر عندما لا توجد APK عامة.

### Animation
حركة الدخول اختيارية وخفيفة للشفافية والتحويل فقط خلال 160–220ms. لا Parallax ولا فيديو ولا Carousel. تُحترم `prefers-reduced-motion`، وتبقى إجراءات لوحة المفاتيح فورية.

### Typography System
العربية: IBM Plex Sans Arabic أو fallback نظامي، والإنجليزية: Inter أو fallback نظامي، مع IBM Plex Mono للـversion وSHA-256. العناوين 600–700، المتن 400–500، وحقول التقنية LTR مع عزل bidi.

### Brand Essence
قارئ Android عربي أولًا متعدد المصادر، يساعد القارئ على اكتشاف XPManga وفهم المصادر وتنزيل النسخة الرسمية دون ادعاءات مبالغ فيها.

Personality: واضح، تقني، متزن.

### Brand Voice
العناوين مباشرة وتشرح الحالة بدل الوعود. الأزرار فعلية ومحددة، والنصوص القصيرة تقول ما يحدث وما لا يحدث.

Example lines:
- «تحقق من حالة الإصدار قبل التنزيل.»
- «يعرض الدليل حالة التكامل داخل XPManga، لا حالة الموقع الخارجي.»

### Wordmark & Logo
تستخدم الواجهة أيقونة XP الحالية كعلامة رمزية، مع كتابة `XPManga` كنص حقيقي بجوارها. لا يُنشأ Wordmark جديد ولا تعتمد الصورة على نص مولّد داخلها.

### Signature Brand Color
`#6D28D9` — XPManga Violet، اللون المملوك للأفعال الأساسية والحالة النشطة.

## Style Decisions

- الوضع الأولي Dark-only؛ لا نضيف Light/Dark toggle في P0.
- لا نستخدم صور مانجا أو شخصيات أو أغلفة خارجية.
- لا نستخدم خدمات تحليلات خارجية أو cookies أو session replay.
- الواجهة لا تعرض مصدرًا أو ميزة أو APK إلا عبر عقد عام أو Feature Publication Gate.
